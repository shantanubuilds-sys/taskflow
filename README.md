# TaskFlow 📝

A simple and lightweight task management web application that helps users organize and track their daily tasks.

## 🚀 Live Demo

Coming soon.

## 📌 About the Project

TaskFlow was built as a beginner web development project to practice building and shipping a complete web application.

The goal was to create a simple task manager with a focused set of core features instead of adding unnecessary complexity.

## ✨ Features

* ➕ Add new tasks
* ✅ Mark tasks as completed
* 🗑️ Delete tasks
* ⌨️ Add tasks using the Enter key
* 📱 Simple and responsive interface

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 💻 How to Run Locally

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
